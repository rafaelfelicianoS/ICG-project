# Assets do Jogador (Mixamo)

Coloca aqui os ficheiros FBX com os nomes exatos:

- character.fbx
- idle.fbx
- walk.fbx
- dribble.fbx
- shoot.fbx
- celebrate.fbx

Regras recomendadas de exportacao no Mixamo:

- `character.fbx`: personagem com skin.
- Clipes `*.fbx`: sem skin, in-place (sem root motion), mesmo rig do character.
